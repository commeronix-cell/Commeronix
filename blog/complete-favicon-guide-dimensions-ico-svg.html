In modern frontend engineering, a missing or broken favicon causes redundant 404 Not Found console errors on every HTTP page request, damages user trust across browser tabs, and depresses click-through rates (CTR) on Google mobile search result pages.

1. Complete Favicon Dimension & Format Standards Matrix

Historically, web developers were forced to create dozens of proprietary icon dimensions. Today, the modern web has consolidated into a clean, standardized set of 5 core assets:

Asset Filename Resolution Target Platform / Context Format
favicon.ico 16×16 & 32×32 Universal legacy browser fallback Multi-layer ICO
favicon.svg Vector (Scalable) Modern desktop Chrome, Firefox, Safari (Dark/Light mode) SVG
apple-touch-icon.png 180×180 px Apple iOS iPhone & iPad home screen bookmark PNG (Opaque)
icon-192.png 192×192 px Android Chrome home screen launcher PNG
icon-512.png 512×512 px PWA splash screen & Google high-res store icon PNG Maskable

2. The Modern, Minimalist HTML `` Setup

Instead of cluttering your HTML document with twenty lines of legacy vendor tags, modern high-performance sites use this clean 4-line implementation: 

<!-- 1. Legacy fallback for old software -->
<link rel="icon" href="/favicon.ico" sizes="32x32">

<!-- 2. Modern scalable vector icon for Chrome, Firefox & Safari -->
<link rel="icon" type="image/svg+xml" href="/assets/favicon.svg">

<!-- 3. Apple iOS home screen launcher -->
<link rel="apple-touch-icon" sizes="180x180" href="/assets/apple-touch-icon.png">

<!-- 4. Progressive Web App manifest for Android -->
<link rel="manifest" href="/manifest.json">

3. Mastering the 180×180 Apple Touch Icon for iOS

When users tap "Add to Home Screen" in Safari on an iPhone or iPad, iOS looks for apple-touch-icon.png. To ensure your icon renders cleanly:

  • Keep it Opaque: Do not use transparent backgrounds for Apple Touch icons. iOS renders transparent areas as solid black, which looks broken. Use a solid background color matching your brand.
  • Do Not Pre-Round Corners: iOS automatically applies its proprietary squircle corner mask. Provide a square 180x180 image.

4. Dynamic Dark Mode Favicons Using Inline Vector SVG

One of the greatest benefits of modern vector .svg favicons is the ability to adapt dynamically when the user switches their operating system between Light and Dark mode using the standard CSS prefers-color-scheme media query embedded directly inside the SVG file: 

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">
  <style>
    path { fill: #111827; }
    @media (prefers-color-scheme: dark) {
      path { fill: #f8fafc; }
    }
  </style>
  <path d="..." />
</svg>

5. How to Fix Stubborn Browser Favicon Caches

Desktop browsers (especially Google Chrome) cache favicons aggressively in a separate internal SQLite database. When updating your website's favicon:

  1. Add a version query string to your HTML links: /favicon.svg?v=2.
  2. Open the favicon URL directly in a new browser tab and press Ctrl + F5 (or Cmd + Shift + R on Mac).
  3. Restart the browser process to clear the persistent memory cache.

6. Frequently Asked Questions

What are the standard favicon sizes for modern websites in 2026?
The minimal standard favicon suite requires: a 16x16 and 32x32 multi-resolution favicon.ico, an SVG icon for modern dark/light mode switching, a 180x180 PNG for Apple Touch devices, and 192x192 and 512x512 PNGs for the Android web app manifest.
Why is my new favicon not updating in Google Chrome?
Browsers aggressively cache favicons to preserve network bandwidth. To force an update, append a version query string to your HTML tag (e.g., favicon.ico?v=2) or clear your local favicon cache.
What are Google's favicon guidelines for mobile search results?
Google requires favicons to be square, at least 48x48 pixels (or multiples thereof like 96x96 or 144x144), and must remain publicly accessible to Googlebot-Image.
