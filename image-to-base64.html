When to Inline Images as Base64 Data URIs

Inlining small icons, SVG emblems, or splash logos directly into HTML or CSS via Base64 eliminates round-trip HTTP request latency. However, because Base64 encoding increases raw binary file size by approximately 33%, large photographs should be served as optimized external WebP/AVIF files with caching headers.
